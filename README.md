# Grey Chair Digital site

A single-page, static site describing Grey Chair Digital's positioning, services, process, and contact details.

## Running locally
Open `index.html` in your browser. Styling is handled by `styles.css` and Google Fonts.

## How to test
- Use a local server (e.g., `python -m http.server 8000`) and visit http://localhost:8000 to view the page with fonts loaded correctly.
- Resize the browser window to confirm the layout adjusts across mobile, tablet, and desktop breakpoints.
- Click the “Schedule a call” and “Get started” anchor links to confirm they scroll to the contact section.
